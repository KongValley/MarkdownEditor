# Markdown 笔记

面向 Windows 7 32 位老设备的离线本地知识库与 Markdown 编辑器。基于 Electron 22（最后一个支持 Windows 7/8/8.1 的版本），编辑器使用 CodeMirror 5，预览使用 marked + highlight.js，全部离线运行。文档始终以纯 Markdown 保存在本地文件夹，不上传、不联网。

## 功能

### 知识库

- 多个本地文件夹注册为知识库：工作台卡片切换，可添加、重命名、从列表移除；移除不会删除磁盘文件。失效路径点击时提示从列表移除后重新添加；移除最后一个库自动回到工作台。
- 侧栏同时显示知识库列表与当前库的目录树；切换知识库时目录、文档列表、标签与搜索上下文一起切换。
- 库首页文档目录：显示内容标题（frontmatter `title` > 首个 H1 > 文件名）、路径、标签、更新时间和字数；支持按更新时间/名称排序与标签筛选。
- 收藏：文档右上角 ☆ 收藏，工作台「我的收藏」可一键打开或取消；重启保留。
- 最近文档：工作台显示最近打开的文档（最多 10 条），可单独删除或清空。
- 跨库全文搜索：回车搜索全部知识库，结果按知识库 → 文档 → 命中行分组，点击跳转到命中行。
- 标签：读取 frontmatter 的 `tags`（`[a, b]`、`a, b` 或缩进列表），用于库内筛选与文档信息栏。
- 双链：预览中 `[[笔记]]` / `[[笔记|显示名]]` 可点击跳转；同一知识库内按相对路径、文件名或文档标题解析。
- 反向链接：文档信息栏显示引用当前文档的其他文档；代码块与行内代码里的 `[[...]]` 不计入。
- 库外单文件仍可打开与保存，但不参与标签、反链与收藏。

### 编辑器（CodeMirror 5）

- 多标签页：同时打开多篇文档，切换保留滚动与光标；关闭时提示保存，支持 `Ctrl+W`；标签栏支持 `←` / `→` / `Home` / `End` 切换与 `Delete` 关闭，活动标签有 `aria-selected` 状态。
- 弹框取消或关闭后焦点回到触发按钮（新建成功后进入编辑器）；搜索无结果时可一键清除，不打断当前文档。
- 三种视图：仅编辑、分栏编辑+预览、全宽阅读；文档头分段按钮切换，`Ctrl+E` 在分栏/阅读间切换，选择会持久化。
- 右侧文档信息栏：大纲、标签、引用；窗口宽度小于 1100px 时自动隐藏，设置中可整体关闭。
- 行号、当前行高亮、软换行、原生撤销/重做。
- 实时预览，GFM 语法（表格、任务列表、删除线、围栏代码块）；frontmatter 不在预览中显示。
- 查找与替换 `Ctrl+F`：命中高亮、上一个/下一个、区分大小写、正则、替换/全部替换。
- 大纲面板：按 `#` 层级生成，点击跳转；阅读模式下按标题滚动预览；光标移动时高亮当前标题。
- 按标题锚点同步滚动：编辑区滚动到某标题时预览定位到对应标题，反向亦然。
- 列表与引用自动续行：`-` / `1.` / `>` / `- [ ]` 行按 Enter 自动补前缀并递增序号，空行退出列表。
- 表格：工具栏插入对齐的 GFM 表格；表格内 `Tab` / `Shift+Tab` 在单元格间跳转。
- 图片：工具栏选择本地图片复制到知识库 `assets/` 并插入相对链接；支持粘贴/拖拽图片落盘；重名自动加后缀。
- 代码块语法高亮（highlight.js，离线）；文档超过 30 万字符时自动关闭高亮与预览以保持流畅。
- 字号、编辑区行宽、自动保存开关与间隔、预览/侧边栏/文档信息栏、远程图片、代码高亮、阅读时间、字数目标、忽略目录均可配置并持久化。
- 编辑区右键菜单：撤销/重做/剪切/复制/粘贴/全选/插入日期时间。
- 状态栏：字数/字符数、字数目标、预计阅读时间、光标行列、换行符、保存状态、知识库路径。

### 文档管理与数据安全

- 目录树：新建笔记/文件夹、重命名、删除（移到系统回收站，可恢复）、在资源管理器中定位。
- 文件名实时筛选；回车执行跨库全文搜索，结果点击跳转命中行。
- 忽略规则：设置中用逗号分隔目录名或通配符（如 `.obsidian, private, *.tmp`），目录树、文档索引与全文搜索同时生效。
- 最近打开列表（最多 10 项）：点击打开文档，每条可单独删除，也可一键清空。
- 设置界面 `Ctrl+,`：主题、字号、行宽、自动保存、侧边栏、文档信息栏、远程图片、代码高亮、阅读时间、字数目标、忽略目录。
- 命令行参数 `MarkdownNotes.exe <文件或文件夹>`：文件夹注册为知识库并打开；文件在库内时切换到该库，库外则作为单文件打开。单实例唤出。
- 自动保存（默认停止输入 0.9 秒后写入，可配置）；`Ctrl+S` 立即保存。
- 保存前比对文件修改时间；被其他程序改动时暂停自动保存，提供「覆盖保存 / 重新加载」。
- 原文件被删除或移动时，提供「另存为 / 放弃」，不会静默丢失。
- 草稿恢复：编辑中的内容写入 `recovery.json`，异常退出后启动时提示恢复为标签页；恢复的草稿在显式保存前不会覆盖磁盘，并保留所属知识库。
- 历史快照：保存前自动保留最近快照（每分钟最多一份，每文件保留 20 份），也可在「历史」中立即备份与载入。
- 保存使用临时文件替换；保留原文件的 LF/CRLF 与 UTF-8(BOM)/UTF-16LE 编码；仅支持这些编码，检测到 GBK 等编码时拒绝打开，避免乱码回写。
- 原始 HTML 在预览中转义显示，`javascript:` 等危险链接移除；外部链接交给系统浏览器。
- 远程图片默认不加载，应用自身不发起网络请求；可在设置中显式开启远程图片（需要网络）。
- 便携模式：`MarkdownNotes.exe --portable`，或 exe 同目录存在 `data/` 时，设置/日志/快照/恢复文件全部写入该目录，不写 `%APPDATA%`。
- 日志：帮助菜单可打开日志目录、复制路径、清空；主进程与渲染错误统一记录到 `logs/main.log`。
- 渲染层启用 `contextIsolation`、`sandbox`、严格 CSP，禁用 Node 集成与远程页面导航。
- 自定义图标：打包时由 `scripts/make-icon.js` 程序化生成多尺寸（16–256）`icon.ico` 并嵌入 exe，窗口/任务栏显示蓝底白色 M；源码不提交二进制图标。

### 数据格式

- 知识库注册表、收藏与最近文档保存在 `settings.json`；文档本身仍是普通 Markdown，可用其他编辑器打开。
- 文档可选 frontmatter：

  ```markdown
  ---
  title: 显示标题
  tags: [知识库, 测试]
  ---
  # 正文标题
  ```

- 双链写作 `[[目标]]` 或 `[[目标|显示名]]`；目标可写相对路径（不含扩展名）、文件名或文档标题。

## 运行环境

- 开发：Node.js 16+（推荐 LTS）、npm。
- 目标设备：Windows 7 SP1（32/64 位）、Windows 8/8.1、Windows 10。
  - Electron 22.3.27 是最后支持 Windows 7 的版本。
  - 建议目标机装齐系统更新（含通用 C 运行库 UCRT / KB2999226）。
  - Windows 7 上默认关闭硬件加速以规避旧显卡驱动崩溃；可用 `--enable-gpu` 对比排查。
- 发布形态：IA-32（x86）免安装 ZIP，解压即用，无需管理员权限；不注册文件关联、不安装服务、不设开机自启。

## 目录结构

```
src/
  main.js              Electron 主进程：窗口、菜单、IPC、设置、知识库注册、日志、便携模式
  main/files.js        文件系统层：目录树、编码读写、忽略规则、搜索、回收站
  main/catalog.js      文档索引：标题/标签/双链/字数，按 mtime 缓存，供目录/标签/反链使用
  main/recovery.js     草稿恢复存储
  main/backups.js      历史快照存储
  preload.js           contextBridge 暴露的受限 API
  shared/text.js       纯函数：查找/替换、列表续行、大纲、表格、字数、frontmatter、双链
  index.html           界面骨架与 CSP
  styles.css           主题、布局与代码高亮样式
  renderer.js          CodeMirror、标签页、工作台、知识库页、搜索、预览、设置、恢复等交互
  vendor/              marked、CodeMirror、highlight.js（由 scripts/vendor.js 复制）
scripts/
  vendor.js            复制并记录依赖版本
  make-icon.js         程序化生成多尺寸 icon.ico（16–256）
  test-text.js         纯函数单测
  smoke-harness.js     Electron 端到端冒烟测试
  package.js           IA-32 免安装打包、PE 校验、启动与便携自检
```

## 开发与构建

```bash
npm ci                 # 安装锁定版本依赖（npm 12 需允许 electron 的 postinstall，见 package.json 的 allowScripts）
npm test               # 纯函数单测：查找/替换、列表续行、大纲、表格、字数、frontmatter、双链
npm run icon           # 生成 build/icon.ico（npm ci / npm start / 打包会自动执行）
npm start              # 开发模式启动
npm run smoke          # Electron 端到端冒烟，66 项断言；报告与截图写入 tmp/
npm run pack:win32     # 生成 dist/MarkdownNotes-<版本>-win32-ia32.zip
```

依赖全部锁定版本：

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| electron | 22.3.27 | 最后一个支持 Windows 7/8/8.1 的运行时（IA-32 包） |
| marked | 4.3.0 | Markdown 解析与 `[[双链]]` 行内扩展 |
| codemirror | 5.65.16 | 编辑器：行号、查找、撤销、语法模式 |
| @highlightjs/cdn-assets | 11.9.0 | 预览代码块离线语法高亮（浏览器构建） |
| @electron/packager | 18.4.4 | 免安装目录、ASAR、ZIP 与 PE 架构校验 |

## 发布

Release 由 GitHub Actions 在云端打包，无需本地出包：

- 工作流 `.github/workflows/release.yml`，运行于 `windows-latest`：`npm ci` → `npm test` → 校验 `package.json` 版本与 tag 一致 → `npm run pack:win32` → 上传 run artifact → 将 ZIP 附加到 Release。
- 触发方式：发布 Release（`release: published`），或手动 `workflow_dispatch`（仅构建并保留 artifact）。
- `SKIP_PACK_SMOKE=1` 让打包跳过 GUI 启动与便携自检（CI 无桌面会话）；本地打包默认执行自检。
- 发版步骤：更新 `package.json` 版本并提交 → `git tag -a vX.Y.Z` 推送 → 发布对应 Release。

## 使用说明

1. 解压 ZIP，运行 `MarkdownNotes.exe`；需要完全便携时运行 `MarkdownNotes.exe --portable`（或在 exe 旁创建 `data/` 目录）。
2. 在工作台点击「添加知识库」选择本地文件夹；侧栏或卡片切换知识库。
3. 库首页查看文档目录，按标签筛选或切换排序；点击文档进入编辑器。
4. 编辑时右侧实时预览；停止输入后自动保存，`Ctrl+S` 立即保存。文档头可切换编辑/分栏/阅读。
5. 点击 `[[...]]` 打开双链目标；右侧信息栏查看大纲、标签与引用。
6. 点击 ☆ 收藏；工作台「我的收藏」集中打开。
7. 顶部搜索框输入关键词回车，跨库搜索并跳转命中行。
8. 右键目录项新建/重命名/删除/定位；右键知识库行重命名或从列表移除。
9. 「历史」按钮查看/创建/载入快照；文件被外部修改时按提示覆盖或重新加载。
10. 异常退出后重启会提示恢复未保存草稿，恢复的内容需显式保存。
11. `Ctrl+P` 打印当前文档（打印样式只输出预览内容）。

## 已知限制

- 双链只在同一知识库内解析，不支持 `#锚点`；重命名/移动文档不会自动改写 `[[...]]` 文本。
- 标签只读取 frontmatter 的 `tags`，不解析正文 `#tag`，本版本不提供标签编辑 UI；库内筛选基于已保存索引。
- 文档索引最多覆盖 3000 篇、单篇 2MB；库首页一次最多渲染 500 篇，超出部分仍可通过目录树或搜索打开。
- 知识库以绝对路径保存；移动文件夹后需从列表移除并重新添加。
- 右侧文档信息栏在窗口宽度 <1100px 时隐藏。
- 代码高亮使用 highlight.js 常用语言集；未注册的语言按纯文本显示。
- 不内置 KaTeX 公式、Mermaid 图表、HTML/PDF 导出、云同步、自动更新。
- Markdown 原始 HTML 出于安全考虑按文本转义。
- 全文搜索为纯文本子串匹配，大小写不敏感；单次每个知识库最多扫描 3000 个文件，全局最多返回 300 条结果。
- 远程图片默认不加载，开启后需要网络；应用自身不发起其他网络请求。
- 仅支持 UTF-8(BOM)/UTF-16LE；GBK 等编码需先转换。
- 发现外部修改的时机为保存前校验；窗口重新获得焦点时会刷新目录树（库首页可见时同时刷新索引）。
- Windows 7 原生 32 位尚未验证，WoW64（64 位系统运行 32 位程序）不能替代。
