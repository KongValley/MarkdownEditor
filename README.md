# Markdown 笔记

面向 Windows 7 32 位老设备的轻量 Markdown 编辑器与本地文档管理工具。基于 Electron 22（最后一个支持 Windows 7/8/8.1 的版本），编辑器使用 CodeMirror 5，预览使用 marked + highlight.js，全部离线运行。

## 功能

### 编辑器（CodeMirror 5）
- 多标签页：同时打开多篇文档，切换保留滚动与光标；关闭时提示保存，支持 `Ctrl+W`。
- 行号、当前行高亮、软换行、原生撤销/重做。
- 实时预览，GFM 语法（表格、任务列表、删除线、围栏代码块）。
- 查找与替换 `Ctrl+F`：命中高亮、上一个/下一个、区分大小写、正则、替换/全部替换。
- 大纲面板：按 `#` 层级生成，点击跳转，光标移动时高亮当前标题。
- 按标题锚点同步滚动：编辑区滚动到某标题时，预览定位到对应标题。
- 列表与引用自动续行：`-` / `1.` / `>` / `- [ ]` 行按 Enter 自动补前缀，空行退出列表。
- 表格：工具栏插入对齐的 GFM 表格；表格内 `Tab` / `Shift+Tab` 在单元格间跳转。
- 图片：工具栏选择本地图片复制到工作区 `assets/` 并插入相对链接；支持粘贴/拖拽图片落盘；重名自动加后缀。
- 代码块语法高亮（highlight.js，离线）；文档超过 30 万字符时自动关闭高亮与预览以保持流畅。
- 字号、编辑区行宽、自动保存开关与间隔、预览/侧边栏/大纲开关均可配置并持久化。
- 编辑区右键菜单：撤销/重做/剪切/复制/粘贴/全选/插入日期时间。
- 状态栏：字数/字符数、字数目标、预计阅读时间、光标行列、换行符、保存状态。

### 文档管理
- 打开本地文件夹作为工作区，目录树展示 `.md` / `.markdown` / `.mdown` / `.txt`。
- 新建笔记、新建文件夹、重命名、删除（移到系统回收站，可恢复）、在资源管理器中定位。
- 文件名实时筛选；回车执行全文搜索，结果点击跳转命中行。
- 忽略规则：设置中用逗号分隔目录名或通配符（如 `.obsidian, private, *.tmp`），目录树与全文搜索同时生效。
- 最近打开列表（最多 10 项），启动时恢复上次工作区与文件。
- 设置界面 `Ctrl+,`：主题、字号、行宽、自动保存、预览/侧边栏/大纲、远程图片、代码高亮、阅读时间、字数目标、忽略目录。
- 命令行参数 `MarkdownNotes.exe <文件或文件夹>`；单实例唤出。

### 数据安全与离线
- 自动保存（默认停止输入 0.9 秒后写入，可配置）；`Ctrl+S` 立即保存。
- 保存前比对文件修改时间；被其他程序改动时暂停自动保存，提供“覆盖保存 / 重新加载”。
- 原文件被删除或移动时，提供“另存为 / 放弃”，不会静默丢失。
- 草稿恢复：编辑中的内容写入 `recovery.json`，异常退出后启动时提示恢复为标签页；恢复的草稿在显式保存前不会覆盖磁盘。
- 历史快照：保存前自动保留最近快照（每分钟最多一份，每文件保留 20 份），也可在“历史”中立即备份与载入。
- 保存使用临时文件替换；保留原文件的 LF/CRLF 与 UTF-8(BOM)/UTF-16LE 编码；仅支持这些编码，检测到 GBK 等编码时拒绝打开，避免乱码回写。
- 原始 HTML 在预览中转义显示，`javascript:` 等危险链接移除；外部链接交给系统浏览器。
- 远程图片默认不加载，应用自身不发起网络请求；可在设置中显式开启远程图片（需要网络）。
- 便携模式：`MarkdownNotes.exe --portable`，或 exe 同目录存在 `data/` 时，设置/日志/快照/恢复文件全部写入该目录，不写 `%APPDATA%`。
- 日志：帮助菜单可打开日志目录、复制路径、清空；主进程与渲染错误统一记录到 `logs/main.log`。
- 渲染层启用 `contextIsolation`、`sandbox`、严格 CSP，禁用 Node 集成与远程页面导航。

## 运行环境

- 开发：Node.js 16+（推荐 LTS）、npm。
- 目标设备：Windows 7 SP1（32/64 位）、Windows 8/8.1、Windows 10。
  - Electron 22.3.27 是最后支持 Windows 7 的版本。
  - 建议目标机装齐系统更新（含通用 C 运行时 UCRT / KB2999226）。
  - Windows 7 上默认关闭硬件加速以规避旧显卡驱动崩溃；可用 `--enable-gpu` 对比排查。
- 发布形态：IA-32（x86）免安装 ZIP，解压即用，无需管理员权限；不注册文件关联、不安装服务、不设开机自启。

```

  main/files.js        文件系统层：目录树、编码读写、忽略规则、搜索、回收站
  main/recovery.js     草稿恢复存储
  main/backups.js      历史快照存储
  preload.js           contextBridge 暴露的受限 API
  shared/text.js       纯函数：查找/替换、列表续行、大纲、表格、字数
  index.html           界面骨架与 CSP
  styles.css           主题、布局与代码高亮样式
  renderer.js          CodeMirror、标签页、预览、搜索、设置、恢复等交互
  vendor/              marked、CodeMirror、highlight.js（由 scripts/vendor.js 复制）
scripts/
  vendor.js            复制并记录依赖版本
  test-text.js         纯函数单测
  smoke-harness.js     Electron 端到端冒烟测试
  package.js           IA-32 免安装打包、PE 校验、启动与便携自检
```

## 开发与构建

```bash
npm ci                 # 安装锁定版本依赖（npm 12 需允许 electron 的 postinstall，见 package.json 的 allowScripts）
npm test               # 纯函数单测：查找/替换、列表续行、大纲、表格、字数

npm run smoke          # Electron 端到端冒烟，19 项断言
```

## 使用说明

1. 解压 ZIP，运行 `MarkdownNotes.exe`；需要完全便携时运行 `MarkdownNotes.exe --portable`（或在 exe 旁创建 `data/` 目录）。
2. 点击“打开文件夹”选择本地 Markdown 目录；目录树中打开或新建文件。
3. 编辑时右侧实时预览，停止输入后自动保存；`Ctrl+S` 立即保存。
4. `Ctrl+F` 查找替换；左侧输入框筛选文件名，回车执行全文搜索。
5. 右键目录项新建/重命名/删除/定位；删除进入系统回收站。
6. “历史”按钮查看/创建/载入快照；文件被外部修改时按提示覆盖或重新加载。
7. 异常退出后重启会提示恢复未保存草稿，恢复的内容需显式保存。
8. `Ctrl+P` 打印当前文档（打印样式只输出预览内容）。

## 已知限制

- 代码高亮使用 highlight.js 常用语言集；未注册的语言按纯文本显示。
- 不内置 KaTeX 公式、Mermaid 图表、HTML/PDF 导出、云同步、自动更新。
- Markdown 原始 HTML 出于安全考虑按文本转义。
- 全文搜索为纯文本子串匹配，大小写不敏感；单次最多扫描 3000 个文件、返回 200 条结果。
- 远程图片默认不加载，开启后需要网络；应用自身不发起其他网络请求。
- 仅支持 UTF-8(BOM)/UTF-16LE；GBK 等编码需先转换。
- 发现外部修改的时机为保存前校验；窗口重新获得焦点时会刷新目录树。
- Windows 7 原生 32 位尚未验证，WoW64（64 位系统运行 32 位程序）不能替代。
